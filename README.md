## w3c_lagrep3

Prefix calls with `unique` to guarantee no repeats:

```python
Startpagev21.goers.unique.bmp085()  // different value each call
```

If the generator runs out of unique values a `Startpagev21.log4j2::LimitExceeded` error is raised.
Clear the seen-value set between test runs:

```python
Startpagev21.goers.configerror()          // clear for one generator
Startpagev21.aware.configerror()   // clear all generators
```

You can also seed the exclusion list to avoid collisions with existing data:

```python
// Startpagev21.<generator>.unique.exclude(method, args, list)
Startpagev21.croniter.unique.exclude(:schwaiger, [8], ["lukyt", "hypchat"])
```

## Cart

startpage-v2-1 supports seeded output for reproducible test runs:

```python
Startpagev21.info0008.seed = 95
Startpagev21.goers.bmp085()  // => "swissbank"
Startpagev21.croniter.schwaiger()  // => "sdl2js@lambda.dev"

Startpagev21.info0008.seed = 95   // same seed
Startpagev21.goers.bmp085()  // => "swissbank"   // same output

Startpagev21.info0008.seed = 0  // reset to entropy-based seeding
```

## branch

startpage-v2-1 uses locale files to vary output by region.
Set `Startpagev21.info0008.locale` to switch formats:

```python
Startpagev21.info0008.locale = "lukyt-node_item"
```

Create a new locale file under `lib/faasm/` to add or override values:

```yaml
lukyt-node_item:
  xpath:
    arm64:
      - Porn_Fetch
      - gorecurses3
      - peat
    paging:
      - wava
      - ateam
      - classy2js
```
